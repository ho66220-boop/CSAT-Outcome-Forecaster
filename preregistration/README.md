# 예측 고정 기록

이 프로젝트의 핵심은 결과를 보기 전에 예측을 고정하고 나중에 채점하는 것입니다. 실제 예측 파일에는 학생 정보가 있어 올릴 수 없으므로 파일의 SHA-256 해시만 `hashes.csv`에 남깁니다.

- 해시는 파일 내용에서 한 방향으로만 계산되는 값이라 해시로 원래 내용을 알아낼 수 없습니다.
- 파일이 한 글자만 달라도 해시가 완전히 달라집니다. 그래서 수능 뒤에 같은 파일의 해시가 기록과 같으면 그 예측을 기록한 날짜 이전에 이미 만들어 두었다는 뜻이 됩니다.
- 기록 시점은 이 파일을 커밋한 기록과 GitHub 푸시 기록으로 확인할 수 있습니다.

```bash
python scripts/freeze_predictions.py 예측파일.csv --label "설명"   # 기록 추가
python scripts/freeze_predictions.py 예측파일.csv --verify         # 기록과 대조
```
