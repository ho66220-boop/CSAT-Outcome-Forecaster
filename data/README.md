# 데이터 형식

`data/sample/`의 파일은 `scripts/make_sample_data.py`로 만든 **가상 데이터**입니다. 학번, 대학 이름, 배치컷은 모두 지어낸 값이며 실제 학생과 관계가 없습니다.

```bash
python scripts/make_sample_data.py --out data/sample --seed 2
```

학생이 100명 안팎이라 시드를 바꾸면 결과도 꽤 달라집니다. 예를 들어 9평 사전 예측의 치우침은 시드에 따라 ±4점 정도 움직입니다. 작은 표본에서는 숫자 하나보다 경향을 봐야 하는 이유이기도 합니다.

## 성적 파일 (`scores_prev.csv`, `scores_curr.csv`, `sept_*.csv`)

한 행이 학생 한 명의 시험 한 번입니다.

| 열 | 내용 | 예 |
|---|---|---|
| 시험명 | `3`, `4`, `5`, `6평`, `7`, `8`, `9평`, `10`, `수능` | 6평 |
| 학번 | 정수 | 900001 |
| 국어, 국표, 국백, 국등 | 선택과목, 표준점수, 백분위, 등급 | 언어와매체, 131, 94, 2 |
| 수학, 수표, 수백, 수등 | 선택과목, 표준점수, 백분위, 등급 | 미적분, 128, 92, 2 |
| 영어, 영등 | `영어`, 등급 | 영어, 2 |
| 탐1, 탐1표, 탐1백, 탐1등 | 과목명, 표준점수, 백분위, 등급 | 생명과학1, 66, 95, 2 |
| 탐2, 탐2표, 탐2백, 탐2등 | 같은 형식 | 지구과학1, 63, 89, 2 |

- 점수 0이나 빈칸은 미응시로 봅니다. 국어·수학·탐구 2과목이 모두 있는 시험만 백분위 합 계산에 씁니다.
- `11수능`, `6월`, `9월` 같은 시험명과 `생1`, `사문`, `확통` 같은 약칭은 읽을 때 표준 이름으로 바꿉니다.
- 엑셀 파일도 됩니다. 첫 행은 머리글로 읽습니다. 열 이름이 위와 같으면 반, 담임 같은 다른 열이 있어도 무시하고, 머리글 이름이 달라도(예: `표준점수`, `백분위`가 반복되는 원본 양식) 20열이 위 순서대로면 위치로 맞춥니다. 양식이 다르면 한 번 위 형식으로 바꿔 두는 편이 간단합니다.
- 9평 파일이 여러 번 갱신되면 설정의 `sept_scores`에 오래된 것부터 적습니다. 새 파일 값을 우선하고, 새 파일에서 빈칸이 된 칸은 이전 값을 유지합니다.

## 재원 명단 (`roster.csv`)

| 열 | 내용 |
|---|---|
| 학번 | 정수 |
| 학년 | `N수` 또는 `고3` |
| 등원일, 퇴원일 | `YYYY-MM-DD`. 재원 중이면 퇴원일은 빈칸 |

기준일(`ref_date`)에 재원 중인 학생만 예측 대상입니다. 3~6월 기록이 있으면 기존 인원, 7·8월 기록만 있으면 6평 이후 등원, 9평만 있으면 9평만으로 나눕니다.

## 배치기준점수표 (`placement.csv`)

| 열 | 내용 |
|---|---|
| 대학명, 모집단위명 | 이름 |
| 군 | 가, 나, 다 |
| 계열 | 인문, 자연, 인자(인문·자연 공통), 예체능 |
| 반영유형 | 국수영탐, 국수탐, 국수영과 등 |
| 탐구수 | 반영 탐구 과목 수 (1 또는 2) |
| 백분위배치컷 | 국어 + 수학 + 탐구 백분위 합 기준 컷 (300점 만점) |
| 영어등급 | 참고용 영어 등급 |
| 전형명 | 일반전형, 지역인재전형 등 |

대학 그룹은 `config/groups.*.json`에서 정합니다. `config/groups.kr.json`은 실제 분석에 쓴 그룹 정의입니다.

## 수동 보정 (`fixes.csv`)

자동 검출에서 `확인 필요`로 나온 값을 원본과 대조한 뒤 적습니다. 수정값을 비우면 그 값을 지표에서 뺍니다.

| 학번 | 시험명 | 열 | 수정값 | 사유 |
|---|---|---|---|---|
| 900012 | 4 | 탐2백 | 46 | 원본 성적표 확인 |

## 검출 확인용 (`injected_errors.csv`)

가상 데이터에 일부러 넣은 입력 오류 목록입니다. 파이프라인이 이 오류를 모두 찾는지 `tests/test_pipeline.py`에서 확인합니다.

## 실제 데이터 두는 곳

실제 학생 데이터는 `data/private/`처럼 저장소 밖으로 나가지 않는 폴더에 두고, 설정 파일도 따로 만드세요. `.gitignore`가 `data/sample/` 밖의 데이터 파일과 모든 엑셀 파일을 커밋에서 뺍니다.
